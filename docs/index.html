Methodology & Fairness

Pinned Toolchains

kizu, zig, go, hyperfine, and just are pinned via SHA-256 in kugi.toml + kugi.lock, paired with system clang and host rustc / cargo.

Runtime-Sized Inputs

All 6 benchmarks add argc - 1 to their workload so compilers cannot constant-fold answers. Every variant is verified to print identical stdout via scripts/check.sh.

Explicit Safety & CPU Flags

Baseline CPU variants: kizu-llvm, kizu-direct, rust (-C opt-level=3), c-O2, zig-fast/zig-safe (-mcpu=baseline), go/go-nobounds. Host-tuned variants: rust-native (-C target-cpu=native) and c-O3native (-O3 -march/-mcpu=native).

Build Caches & Host Separation

Cold builds start with empty project caches and warm stdlib/runtime caches. Cache sizes record exact bytes of KIZU_CACHE_DIR, Rust target/, GOCACHE, .zig-cache, and C .o files. macOS Apple Silicon and Linux x86_64 runs are always kept separate.
